mend is one patch tool for every AI edit format: it applies unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON edits to a tree of text files, with three-tier line matching, per SPEC.md. `main.ts` is the tool; `runner.ts` is the trial runner from the kit. Entry for the [hidden-spec-cli bounty on make.fun](https://make.fun/bounty/hidden-spec-cli-01-run-20261122).

## Run it

```sh
node main.ts [options] [PATCH]
```
